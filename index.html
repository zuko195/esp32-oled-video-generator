The ZIP contains ESP32_OLED_Animation.ino, animation.h, and README.txt.
OLEDFrame Studio is a standalone ESP32 OLED project. Default wiring: SSD1306 SDA → GPIO 21, SCL → GPIO 22, address 0x3C. This browser MVP processes uploaded videos or direct video URLs; server-side YouTube retrieval is a separate planned component.
